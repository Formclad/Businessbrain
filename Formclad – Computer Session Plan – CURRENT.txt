FORMCLAD – COMPUTER SESSION PLAN
Version 1.0 | 18 September 2026
The things that need a computer, in the order that gets the most value from one sitting. Allow about 90 minutes for all of it, or pick off items 1 to 3 in 30 minutes.

Before starting: install Claude in Chrome, so Claude can see the screens and drive them with you watching.


1. PROJECT FOLDER AUTOMATION (about 20 minutes)
Goal: every new job folder is created with the standard structure already in it, including 05 - Close-Out and its checklist.

Option A — SharePoint document sets (preferred: nothing to maintain, nothing to break)
  a. Site settings > Site collection features > enable "Document Sets" if not already on.
  b. Site settings > Site content types > create a content type, "Formclad Project", based on Document Set.
  c. In its Document Set settings, add the default folders: 01 - Commercial, 02 - Drawings & Technical, 03 - Correspondence (as per current structure), 04 - Safety & Quality, 05 - Close-Out with its six subfolders.
  d. Add the default content: the close-out checklist, and any other template documents that should start in every job.
  e. Projects library > Library settings > allow management of content types > add "Formclad Project".
  f. Test: create one, confirm the structure appears.
Every new project is then created from that content type and arrives complete.

Option B — Power Automate (fallback if content types are restricted)
  a. Build a MANUAL trigger flow ("Create project folders"), not an automatic one. Input: job number and name.
  b. Action: create the folder, then copy the contents of Projects > Filing System into it.
  c. Manual triggers avoid the runaway-trigger problem behind the 116 failures in the Tender Tracker flow.

Later, worth exploring: whether Nexvia can trigger this when a tender is converted to a project, so one action creates both the Nexvia project and the SharePoint folders.


2. THE FAILING FLOWS (about 15 minutes)
  a. Open "Formclad - Create Tender Tracker From Folder" run history. Look at: what triggers it, which step is red, and what the error says. 116 failures in a week means it is firing on every file rather than once per tender folder.
  b. Open "Formclad - AI Prequalification". An earlier notice said "Missing Copilot Credit or AI Builder credit capacity" — that is a licensing limit, not a broken flow, so it will keep failing until credits are added or the AI step is replaced.
  c. Screenshot each failed step, or let Claude read them through Chrome.


3. NEXVIA: BUDGET AND EXTENT OF WORKS (about 20 minutes)
Do this on ONE job that is just starting, not a live claiming job — activating extents changes what the progress claim reads from, which is not something to test mid-job.
  a. Check which labour types exist: Hours screen > Edit Labour Types. The crew's app options come from these, so the target is Roofing Labour and Cladding Labour (plus establishment/access if useful).
  b. On the test job: Budget > Hours > Import Labour Materials, then correct the rates ($80 cost; charge-out to be confirmed — $110 in the master, $115 on the project, $120 in an older reference).
  c. Budget > Assembly > Options > Activate Extent of Work > Create All > check allocated per cent > Create Extent of Works. Remember this can only be run once per project.
  d. Have someone open the app and confirm they see the short list.
  e. Save the result as an Extent of Works template for reuse.
  f. Write the exact steps into "Formclad – Nexvia Project Setup" so anyone can repeat them.
Also: read the Nexvia wiki through Chrome on how extents interact with progress claims, before changing anything on a job with claims running.
